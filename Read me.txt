# Auckland Aquarium Management System

## Project Description

This project was developed for Week 7 Activity 2.  
It is a Python CLI-based aquarium management system for an aquarium in Auckland.

The system allows the user to enter the number of fish currently available in the aquarium and display the fish name, fish category, and available count.

The fish types included are:

- Goldfish
- Shark
- Angelfish
- Tuna
- Salmon

## Design Patterns Used

This project uses both:

- Factory Design Pattern
- Singleton Design Pattern

## Factory Design Pattern

The Factory Pattern is used through the `FishFactory` class.

The purpose of the factory is to create fish objects based on the user’s menu selection.

For example:

- Choice 1 creates a `Goldfish` object
- Choice 2 creates a `Shark` object
- Choice 3 creates an `Angelfish` object
- Choice 4 creates a `Tuna` object
- Choice 5 creates a `Salmon` object

This avoids creating fish objects directly in the client code.

## Singleton Design Pattern

The Singleton Pattern is used in the `AquariumManager` class.

This class manages the SQLite database connection and fish records.

The Singleton Pattern ensures that only one aquarium management object is created during the program execution.
