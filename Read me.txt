# EXPLANATION OF FACTORY DESIGN PATTERN

# 1. The client does not directly create Dog() or Cat()
# 2. The factory classes handle object creation
# 3. This reduces tight coupling in the program
# 4. The code becomes easier to maintain and extend
# 5. New animal types can be added easily in future
